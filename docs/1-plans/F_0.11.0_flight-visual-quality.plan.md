# Flight lighting, ground materials and optional high graphics

## Overview

Correct washed-out aircraft lighting and flat airfield materials, and expose a practical High graphics option for stronger PCs. Keep Balanced suitable for the M3 and preserve one browser tab. Trees and birds are the explicitly requested next task, after this pass is complete.

## Problem

The final HDR composer uses multisampling=0, so Canvas antialias=true does not smooth the actual offscreen scene. There is no final scene anti-aliasing pass. The airfield only modulates color with very weak value noise, so pavement has no convincing aggregate/roughness/normal detail. Aircraft PBR uses the atmosphere's already-scaled sunlight color multiplied by another 2.4, but ambient illumination is still a fixed blue hemisphere. The source hull has roughness0.94 and canopy glass0.965; the existing adapter clamps do nothing to those values. The2K hull map has correct sRGB/trilinear mipmaps but anisotropy1; normals are sound and must be preserved. PBR receivers are excluded from the atmosphere relighting mask and therefore miss cloud attenuation.

## Architecture

- A small flight-only graphics configuration owns Balanced and High. Balanced keeps DPR1 and the current medium cloud budget, adds modest final SMAA, and retains a1024 local shadow map with8x texture filtering (hardware bounded). Both presets cap scene allocation at2.5M pixels so High cannot render at a lower resolution than Balanced on large displays. High requests DPR1.5, stronger SMAA,2048 local shadows, and 16x anisotropic material filtering (hardware bounded). Explicit diagnostic dpr/quality/exposure overrides remain supported and are recorded. Clamp render dimensions to actual hardware. Set the FLIGHT Canvas WebGL context to antialias:false and keep composer multisampling at0: scene color, normal and lighting-mask buffers must retain matching single-sample coverage; DPR plus final SMAA provides the High AA path without silhouette halos. Cloud view pixels retain their existing1.5M ceiling, including in High; increased scene resolution must not silently expand cloud memory. Use the graphics=balanced|high query and docking.flight.graphics.v1 local-storage key. Precedence is valid explicit graphics query, then valid stored preset, then Balanced. The frozen cloud-base fixture ignores storage and retains legacy rendering on load unless a valid graphics query is present. A deliberate paused graphics-panel choice is also an explicit opt-in; stored preferences alone never alter the reference fixture. Apply explicit diagnostic dpr, quality and exposure overrides last, then safety caps; reject nonfinite/invalid overrides. Storage access is guarded. User changes quality while paused and keeps pose/time/input ownership.
- Reuse the installed postprocessing SMAA implementation in a separate final EffectPass after the atmosphere/tone-mapping EffectPass; SMAA.update must receive the already-tonemapped image, not a shared pass's pre-atmosphere HDR input; no custom temporal scene AA or sharpen filter. Preserve identity defaults for LibraryEffects when these new explicit flight options are absent. Keep original frozen cloud-base diagnostic rendering defaults unless graphics is explicitly requested through its query or paused panel. Composer resize must respond to DPR changes even at unchanged CSS size. Resource replacement must cleanly dispose old AA buffers, composer targets and borrowed refs; no extra canvases or game tabs.
- Correct local PBR radiometry using the existing atmosphere library. getSunLightColor already includes solar irradiance and relative luminance: use unit direct intensity with the existing horizon visibility factor. Borrow the already-loaded irradiance LUT and use SkyLightProbe for actual daylight-dependent diffuse sky illumination. Its basis must be an orthonormal world/ECEF rotation: render-meter scale must not multiply spherical-harmonic coefficients. Any small ground bounce is explicit and energy-bounded. Static fixture lighting remains the legacy path. Do not add a static HDRI or a second tone mapper/exposure just for the plane.
- Give owned aircraft/airfield PBR materials the same cloud visibility as terrain. Reuse existing canonical media/transport/lookup shaders and live uniform identities, transforming local render positions into physical ECEF once. Multiply direct irradiance and diffuse sky separately, before the BRDF; do not darken emissive markings or final color. Use the existing valid light cache, with bounded production cloud-transport fallback when outside/invalid. Change EveAerialPerspectiveEffect so masked PBR pixels skip irradiance and cloud integration while retaining atmospheric transmittance/inscatter and the cloud overlay. Compute footprints before divergent branches. Benchmark invalid-cache startup and quality switching separately from steady state so fallback is not charged twice to the same visible pixel. Compose material hooks with existing surface hooks; retain the existing aerial mask to prevent double lighting. Shader ABI changes fail clearly. Original assets/cached GLTF materials/textures stay untouched.
- Ground materials gain deterministic tileable aggregate and roughness/normal information in owned mipmapped textures, with site-local meter mapping and bounded anisotropy. Reuse the surveyed apron/runway masks and derivative-filtered joints; introduce clear asphalt/concrete/infield differences and gentle large-scale wear. Preserve collision geometry, non-overlapping deck partitions and11 instanced batches. No per-frame texture work or displacement. Filter fine detail at distance instead of introducing noisy shimmer.

## Visual-verification correction

The first overcast comparison exposed a shared ambient-transport defect: using direct Beer extinction for diffuse sky turned the aircraft almost black beneath bright clouds. The shared ambient cache/fallback now integrates absorption and transport scattering separately, using a symmetric two-flux slab approximation along the existing cosine-weighted paths. Its conservative limit is `T=1/(1+(1-g)*tau/2)`; pure absorption retains Beer transmission. Direct shadows retain their existing integrator. This changes the scalar ambient quantity consistently for terrain, aircraft and the cloud view, without another cache/channel or ray budget. It is a bounded approximation, not full 3D multiple scattering or a solar-to-diffuse source solution. Validate physical endpoints on the GPU and repeat the affected visual/performance checks. Basis: [Coakley–Chylek conservative solution, eq.11](https://amt.copernicus.org/articles/13/3909/2020/) and the [two-stream transfer coefficients](https://proteus-framework.org/SOCRATES/Explanations/two_stream.html).

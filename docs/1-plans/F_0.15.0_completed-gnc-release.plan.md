# v0.15.0 — Under the Hood

Release scope authorized September 17, 2026, including the hosted game on
Cloudflare Pages. This is a bounded release of completed increments from the
larger development plans, not completion of those entire roadmaps.

## Included

- Reviewed and live-accepted first-docking guidance, input, geometry and retry fixes.
- Opt-in GNC Lab: traced nominal/fault sessions, signal diagram and inspector,
  stepping, plots, recorded-run comparison, JSON/CSV export and validated import.
- Deterministic Node Monte Carlo CLI with paired seeds, worker threads,
  manifest/bundle identities, failure accounting and aggregation.
- Reviewed pure-core trace, world-anchor, mount/calibration and IMU foundations.
- Reviewed procedural vehicle and ascent physics; no launch guidance/UI claim.
- Native MATLAB/Simulink six-DOF plant and separate LQR analysis, with refreshed
  fixtures and a new actual MATLAB verification run before release.

## Excluded

Unfinished atmosphere/cloud replacement, private third-party shader extracts,
rocket guidance and launch interfaces, Runpod deployment helpers, full GNC
session replay, live MATLAB/SIL/HWIL integration, personal study/interview
material and research/worker ledgers. Existing production weather remains the
released baseline. No personal artifacts are added by broad staging.

## Isolation and validation

An explicit file manifest and alternate Git index define the candidate.
Workers finish at a safe boundary before the parent temporarily validates that
candidate in the single primary checkout. Excluded dirty files are preserved
locally and restored with hash checks; no second project or worktree is used.

Run workspace tests, workspace type/build checks, the real Monte Carlo bundle
and equivalence test, fixture freshness checks, and native MATLAB/Simulink
verification. Inspect the production game in one browser context, covering
mission entry and the GNC route. Verify deployment identity and hosted routes
after the existing GitHub-to-Cloudflare deployment completes.

## Review

Retain the existing independent approvals for unchanged completed slices.
Review the final GNC outcome/import corrections and the combined release
boundary. Record actual reviewers and checks in the release CR; absence of a
single feature-loop state file is not a claim that review was skipped or trivial.

## Documentation impact

Root version, README, ARCHI, testing instructions, the first-docking memo,
public GNC usage/scope notes, MATLAB README/API/verification, release review
and changelog. Broader feature plans remain development documents and are not
promoted to fully completed status by this release.

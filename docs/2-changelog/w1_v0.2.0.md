## Changes

- **Telemetry bus** (`apps/web/src/telemetry/`): zustand store as the single sim→UI seam; deterministic stub emitter at FSW_HZ (seeded mulberry32, V-bar approach profile 250 m → 25 m hold, frame-count-driven sim time, no wall clock). Phase 2 swaps one file to go live.
- **Cinematic scene** (`apps/web/src/scene/`): custom Earth shader (day/night terminator blend, water-mask sun glint, additive fresnel atmosphere) in an angular-size-preserving scaled group with logarithmic depth buffer; ESO Milky Way background (intensity clamped below bloom threshold); sun direction shared between light and shader via `sun.ts`; half-res bloom with an HDR contract (only night lights and glints exceed luminance 1.0); primitive station + capsule chaser honoring the ±ŷ docking-axis convention, chaser driven by bus nav position with low-bandwidth render damping (λ=1.5, tuned post-review against nav-noise jitter).
- **HUD skeleton** (`apps/web/src/hud/`): phosphor flight-software theme; telemetry strip (RANGE, CLOSING via 1 s baseline + EMA, NAV σ RSS, PROP placeholder, MET), 6-tile caution/warning grid (inactive), controller/mode bar bound to telemetry.
- **Assets** (`apps/web/public/assets/`): NASA-derived Earth textures (2k), ESO starmap (4096×2048 LDR, CC BY 4.0), provenance + license + normalization contract in `ASSETS.md`. Spacecraft glTF deferred (documented primitive fallback; drop-in path defined).
- **Tooling**: local tooling sandbox guard — the Windows bypass flag now applies only when the machine-local local config grants elevated-permission to this exact checkout (git-root vs config-key comparison).
- **Coverage debt**: `COVERAGE-DEBT.md` opened for the stub emitter and closing-rate estimator (apps/web has no test runner yet).

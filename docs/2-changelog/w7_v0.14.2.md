# Changelog - Week 7, 14-09-2026, V. 0.14.2

**Release Date**: Week 7, 14-09-2026 at 18:56
**Version**: 0.14.2 (previously 0.14.1)
**Object**: chore: retire the v0.8.0 renderer — remove the legacy cloud stack, starfield, bloom composer, water overlay and unused textures
**Code review**: `docs/3-code-review/CR_w7_v0.14.2.md` (focused independent review)

## Changes

- **Why**: v0.14.1 made the library atmosphere pipeline the only renderer but left the v0.8.0 renderer in the tree as unreachable code and shipped its textures. This release removes it.
- **Deleted modules**: `scene/Effects.tsx` (legacy bloom/tone-map composer), `Starfield.tsx`, `SunSprite.tsx`, `Clouds.tsx` (textured deck and cirrus shells), `VolumetricClouds.tsx` (12,000 seeded billboard puffs), `cloudCoverage.ts` + `sky/cloudCoverage.ts` (coverage transfer function GLSL), `sky/cloudPlacement.ts` (mask rejection sampling), `sky/lighting.ts` (artistic terminator ramp GLSL), `EarthMath.ts`, and their tests (17 cases covering only the removed code).
- **Collapsed to the library path**: `Earth.tsx` is now an opaque globe emitting linear albedo + water metadata (day + water-mask textures only; no atmosphere shell, LUT uniforms, night lights, relief normals or cloud shadows); `terrain/terrainShaders.ts` keeps one opaque terrain material (no `LIBRARY_LIGHTING` GLSL branches, no procedural palette, no water overlay shaders); `TerrainPatches` drops the `opaque`/`libraryRenderer`/`cloudMap`/`transmittanceLut`/`mainDeckRotation` props, the alpha fade and the animated water mesh; `ThrusterPlumes` always renders on the exhaust layer without depth test; `RenderProbe` reports `library` only; `renderProbeConfig` no longer exports `LIBRARY_RENDERER`; `FlightMode` passes no renderer props to `Earth`. `FRAME_TONE_MAPPING` moved to `scene/frameToneMapping.ts`; `cloudSphericalUv` moved to `sky/cloudSphericalUv.ts` (still the canonical equirect mapping the terrain and weather tests pin against).
- **Assets and scripts**: removed `textures/earth_night_2k.ktx2`, `earth_normal_4k.ktx2`, `earth_clouds_4k.ktx2`, `cloud_coverage_mask.png`, `hdri/starmap.jpg` (≈16 MB the site no longer serves) and `scripts/makeCloudMask.mjs`, `makeEarthNormal.mjs`. `ASSETS.md` rows removed with a note; the keybinds credits now carry the Crew Dragon and F/A-18C CC BY 4.0 attributions and the NOAA/USGS terrain sources instead of the starfield; the personal site drops the ESO credit for the same reason.
- **Config**: `skyConfig.ts` exports only constants that still have consumers; `SKY_CONFIG`/`SKY_DERIVED` inputs and their derivation oracles are unchanged.
- **Tests**: `terrainSurfaceCoverage.test.ts` and `libraryWaterLighting.test.ts` now pin the single opaque-surface contract (no water overlay, `transparent: false`, no renderer switch); `libraryEarthTextureOrientation.test.ts` checks the three remaining KTX2 textures; `renderEvidenceName` drops the `old` backend.
- **Not changed**: cloud density, weather content, Takram passes, FLIGHT graphics presets, physics, mission logic. The LUT bake (`scripts/bakeAtmosphere.mjs`, `assets/lut/`) stays because the sandbox sun tint samples the transmittance table.

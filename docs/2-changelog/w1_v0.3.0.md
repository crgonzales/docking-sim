## Changes

- **Truth dynamics** (`dynamics.ts`): CW ODE + RK4 @ 100 Hz, verified against the `propagateCW` analytic oracle over multiple orbits; kinematic LVLH attitude hold (q_BI at ω = n·ẑ) pending Phase 3's real 6-DOF.
- **RCS model** (`thrusters.ts`): 16 canted jets in 4 corner clusters (25 N, 20 ms min impulse, Isp 220 s), truth-tick quantization, propellant depletion, per-jet failure states (`nominal/isolated/stuck_open/stuck_closed`).
- **Allocator** (`allocator.ts`): bounded active-set NNLS over on-times with torque-minimizing secondary objective, FSW availability mask, pre-quantization-residual `sat_flag`.
- **Sensors** (`sensors.ts`): seeded range/bearing/gyro/attitude with degrade hooks (bias ramp, dropout, noise multiplier) — the Phase 5 `NAV_DEGRADE` surface.
- **EKF** (`ekf.ts`): 6-state translational filter, exact discrete CW transition, Joseph-form updates, previous-tick quantized-impulse control input; **50-run ANEES consistency gate at the honest 95% χ²₆ₙ/N band** in the test suite.
- **Guidance & control** (`guidance.ts`, `control.ts`): V-bar glideslope to a 30 m hold; PID and LQR (numeric discrete Riccati). Default tuning is deliberately conservative — approach is slow but stable; a tuning pass rides with Phase 4's MPC work.
- **FSW composition** (`fsw.ts`): pure `FswTick` closure per ARCHI (never reads truth; grep-enforced), operator command surface, FSW-side prop estimation.
- **SimLoop** (`sim.ts`): the public seam — `stepTo(t_s): TelemetryFrame[]`, command API (`setController`, `isolateThruster`) vs injection API (`injectThrusterStuck`, sensor degrade) honesty split, truth-privileged NEES + prop published per frame.
- **Web**: `stubEmitter` deleted; `simEmitter` drives the Phase 1 bus from the real loop (fixed seed, sim-time-driven). HUD PROP live from the truth tank. apps/web gained Vitest (closing-rate estimator extracted to a pure module + tested; emitter determinism tested). Coverage-debt ledger cleared.
- **Review fixes of note**: nominal jets originally never fired in truth (min-impulse re-applied per truth-tick slice) and the HUD gauge showed FSW's belief instead of the tank — both caught by code review, fixed with regression assertions. A batch's attempt to widen the failing ANEES band (z=5.5) was reverted; the real causes (R mismatch, phantom Q) were fixed instead.

Tests: 40 (35 sim-core, 5 web). Implementation landed in 5 reviewed batches.

## Changes

- **Attitude truth** (`attitude.ts`, `dynamics.ts`): Hamilton scalar-first quaternion algebra with a direction-named frame chain (q_BH/q_HB, epoch-aligned Hill/inertial at t=0); rigid-body Euler equations (diagonal inertia 600/400/600 kg·m²) with thruster torques, RK4-integrated; oracles: single-axis spin closed form, full-vector inertial momentum conservation in an asymmetric spin, norm drift < 1e-9/10⁴ steps. The Phase 2 kinematic LVLH hold is gone — the hold is now a real closed loop.
- **MEKF** (`mekf.ts`, `sensors.ts`): 6-state multiplicative EKF (attitude error + gyro bias) fusing bias-corrupted gyro (seeded random walk) and star tracker; truth-privileged `getTrueGyroBias()` diagnostic; honest 50-run attitude ANEES gate at the 95% χ²₆ₙ/N band.
- **Six-target allocation** (`allocator.ts`): commanded force AND torque as first-class NNLS targets with per-axis weights and per-block sat thresholds (floor + 5%).
- **FSW** (`fsw.ts`, `ekf.ts`, `control.ts`): MEKF-first wiring with four explicit frame conversions via the attitude estimate (attitude-aware bearing h with R inflated by J_θ·P_θθ·J_θᵀ, AUTO force H→B, achieved impulse B→H, RATE sticks B→H); mode branch AUTO / MANUAL-RATE (stateful capture-integrate-latch reference generator, controller reset on every RATE entry) / MANUAL-PULSE; docking telemetry (closing/lateral/misalign/rate) gated on NAV range.
- **SimLoop** (`sim.ts`): deterministic manual command API (`setControlMode`/`setManualSubMode`/`setManualCommand` — a scripted (t, command) sequence reproduces a flight bit-exactly), truth `getRenderState()` (visuals=reality, gauges=FSW belief), truth-side attitude NEES per frame.
- **Web**: truth render channel on the bus; chaser pose slerp from truth attitude; mouse+keyboard manual controls (WASD+R/F translate, right-drag pitch/yaw, Q/E roll, M/T/C mode keys) with fail-safe zeroing on blur/hide/pointercancel/mode-exit; camera rig (CINEMATIC/CHASE/COCKPIT with viewport frame); docking-camera PiP as a post-composer scissor pass sharing one measured rectangle with its crosshair overlay, envelope numbers colored against the Phase 5 capture envelope; HUD gains ATT σ, RATE, and mode/sub-mode chips.
- **Review catches of note**: swapped roll/yaw axis mapping, PiP drawn before the composer (invisible), stale drag rotation re-issued after mouse-up, dropout blanking the docking display, missing integrator reset on RATE entry — all found by code review after a live flight test had passed, and all regression-fixed.

Tests: 61 (56 sim-core, 5 web). Verified live: manual burn raised closing 0.11→0.20 m/s with real prop depletion; mode, sub-mode, and camera switching all exercised in-browser.

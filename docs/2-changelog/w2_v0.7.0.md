# Changelog - Week 2, 15-08-2026, V. 0.7.0

**Release Date**: Week 2, 15-08-2026 at 21:10
**Version**: 0.7.0 (previously 0.6.0)
**Object**: feat: flight feel — selectable manual authority, truth-driven thruster plumes & procedural RCS audio
**Code review**: `docs/3-code-review/CR_w2_v0.7.0.md` (review loop, 2 rounds -> APPROVED with observations)

## Changes

- **Manual control feel**: measurement showed two independent limiters — a 1.5 deg/s
  rate cap using ~6% of available torque, and an attitude loop at ωₙ ≈ 0.45 rad/s,
  ζ ≈ 0.34 that overshot 32% and took >15 s to settle. Manual now resolves through
  `LOW`/`HIGH` authority presets (`MANUAL_AUTHORITY_PRESETS`) with their own gains,
  reaching commanded rate within 1.5 s at ≤10% overshoot on `HIGH`. `LOW` reproduces
  v0.6.0 behavior exactly.
- **AUTO is untouched by construction**: manual gains route through a new
  `stepManualDamping` entry point, leaving `step()`/`stepAuto()` on AUTO gains. This
  matters because `fsw.ts` shares `step()` with the ABORT COASTING damping path — a
  regression test asserts abort torque is identical across authority levels.
- **Authority is a deterministic command**: `setManualAuthority` on `FswTick`/`SimLoop`
  alongside the other operator commands, published in `TelemetryFrame`, reachable via
  the MISSION panel, the `G` keybind, and both telemetry emitters.
- **Scenario pinning**: scenario runs pin `initialManualAuthority: 'LOW'` only — not
  per-field overrides, which would outrank presets and make the MISSION switch inert.
  The perfect-operator acceptance test is unaffected; no schema change (`schema_version`
  stays 1).
- **Truth-driven thruster plumes**: `RenderState` carries per-jet duty accumulated
  across the truth ticks of each FSW window and latched at the boundary — sampling a
  single 10 ms tick would have aliased normal short pulses away. Sourced from truth, so
  a stuck-open jet renders a plume even when FSW believes it commanded nothing.
- **Plume rendering**: shader-based soft falloff (radial + longitudinal) with a hot
  axial core, 24 radial segments, duty-driven length at near-constant radius, and
  per-jet flicker. Allocation-free render loop.
- **Procedural soundscape**: shared `AudioContext` + master gain extracted from
  `panelAudio.ts` so one mute covers clicks, alarm, and flight audio. A single pooled
  filtered-noise RCS voice tracks aggregate duty (not one node per jet per tick),
  over an ambient hum, with a contact thump on DOCKED/COLLISION only and outcome
  stingers sourced from scenario state. Continuous voices tear down when the HUD
  unmounts, since ANALYSIS swaps it out entirely.
- **Tests**: 125 passing (105 sim-core, 14 scenario, 6 web). New coverage for the
  HIGH acceptance case, the paired tumble regression, abort-torque authority
  invariance, authority-switch continuity, sub-window pulse duty, and stuck-open
  plume honesty.

addendum).

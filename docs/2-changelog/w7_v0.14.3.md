# Changelog - Week 7, 15-09-2026, V. 0.14.3

**Release Date**: Week 7, 15-09-2026 at 19:20
**Version**: 0.14.3 (previously 0.14.2)
**Object**: hotfix: open the bare URL on the first-docking mission; sandbox, analysis and flight stay explicit modes
**Code review**: `docs/3-code-review/CR_w7_v0.14.3.md` (focused independent review)

## Changes

- **Entry point**: the bare URL (and any missing, empty or unknown `?mode=` value) now opens MISSION, which shows the first-docking briefing. `?mode=sandbox` opens the autopilot approach, `?mode=analysis` the Monte Carlo screen and `?mode=flight` the F/A-18 flight base. The resolver is exported as `resolveAppMode` and unit-tested; `App` already starts the scenario publisher when MISSION is the initial mode.
- **Site**: carlosgonzales.dev keeps its blurred ambient background on `?mode=sandbox` so no briefing dialog sits behind the portfolio text; pressing Play loads the simulator root (the mission) into the same frame before focusing it. The `/docking-sim` redirect and the `#play-link` fallback are unchanged.
- **Docs**: ARCHI and README state the new default and the explicit modes.
- **Not changed**: mission content, sandbox behaviour, renderer defaults, FLIGHT.

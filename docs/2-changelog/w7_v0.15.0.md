## Changes

- Add an explicit lazy-loaded GNC mode with the real traced nominal/fault
  loop, causal signal diagram, inspector, plots, pause/step controls and
  bounded recording. Imported run evidence stays separate from LIVE data.
- Export and validate run JSON/CSV, including identity, completeness and
  terminal outcome. Handle FSW aborts that occur after the last plant sample.
- Add the headless Node Monte Carlo CLI: paired seeds, manifest/bundle
  identities, worker threads, restartable shards and failure-aware aggregation.
  Build its actual executable in CI before running bundle-equivalence tests.
- Add the native MATLAB/Simulink six-DOF plant, pulse/fault experiments,
  analytic/conservation checks and separate LQR analysis. Refresh source-hashed
  reference data and execute the native verification again for this release.
- Add reviewed world-anchor, mount/calibration and IMU frame handling, with
  actual installation separated from the calibration available to FSW.
- Add reviewed procedural vehicle and ascent core APIs: mass/inertia,
  approximate aerodynamics, fuel/thrust, separation, parachutes and contact.
- Correct first-docking controls, port-relative readouts and guide rings,
  maintained approach across precision changes, exercise retry and debriefs.
- Document current behavior and limits; add named feature releases to README
  Build History before Credits.

## Boundaries

The current production renderer is retained. The unfinished volumetric weather
port and its private source extracts are excluded. Rocket guidance/designer/
launch UI, GPS/radio, remote Runpod execution, full session replay and live
MATLAB/SIL/HWIL remain development work. Existing flight and mission defaults
remain available. Personal study/interview files are not part of this release.

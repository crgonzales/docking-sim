# Postmortem: v0.4.0 manual-translation tumble (fixed in v0.4.1)

**Symptom** (user report): pressing `W` in MANUAL pitched the vehicle instead
of translating. Regression test showed a 175° attitude excursion in 20 s in
both RATE and PULSE.

**Three compounding defects**, uncovered in sequence by instrumented runs:

1. **Allocator sacrificed torque under saturation.** Manual velocity steps
   drove the LQR into force demands that saturated all 16 jets; with force
   and torque rows at comparable weights, the unit mismatch (tens of N vs a
   few N·m) made torque error cheap to sacrifice — the canted-jet coupling
   torque then tumbled the vehicle faster than the attitude loop could
   respond. *Fix: lexicographic force back-off — if torque tracking is
   sacrificed, halve the force command and re-solve (translate slower, never
   tumble). Weight-skewing was tried first and rejected: the active-set NNLS
   loses convergence at strongly skewed row scales.*

2. **Min-impulse deadband silently zeroed fine control.** Torque-balanced
   solutions spread impulse across many jets; per-jet on-times below the
   20 ms minimum were zeroed wholesale, so small commands produced **no
   thrust at all** (this also affected AUTO's fine corrections since Phase 2,
   masked by loose test tolerances). *Fix: per-jet impulse accumulators (PWM
   across FSW cycles, standard real-RCS practice) — sub-minimum demand
   carries to later ticks and average thrust is honored.*

3. **PULSE mode had no rate damping**, so any residual coupling torque
   integrated unopposed. *Fix: PULSE keeps pure rate damping (PD stepped with
   the current attitude as its own target) — no attitude/position hold, like
   real direct-RCS modes.*

Plus a guard: MANUAL translation force is capped (`manualForceLimit_N`,
default 60 N) so the allocator always retains torque authority.

**Result**: max excursion 175° → <1° in both sub-modes (regression:
`manual-coupling.test.ts`); live burn raises closing rate with body rates
*decreasing*.

**Lessons**
- Closed-loop tests must cross-couple the axes they claim to cover: every
  Phase 3 test drove attitude OR translation, never both at once. The
  one-line regression that catches all of this is "translate and assert the
  nose stays put."
- `sat=true` on every tick in the diagnostic was the tell; saturation
  telemetry deserves a HUD/C&W surface (Phase 4/5 candidate).
- Loose assertions ("prop < 24", "hold distance decreased") let the deadband
  starvation defect ship in v0.3.0. Assert magnitudes, not directions.
